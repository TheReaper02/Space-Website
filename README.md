# Space Tourism Website

This project is a responsive multi-page website built as a Frontend Mentor challenge. The goal was to recreate the Space Tourism design from Figma using semantic HTML5, Tailwind CSS (via CDN), and vanilla JavaScript for dynamic content and navigation. The site features:

- Fully responsive layouts for mobile, tablet, and desktop
- Custom navigation with mobile menu and desktop bar
- Dynamic content switching for destinations, crew, and technology pages
- Accessibility best practices and semantic markup
- Figma-accurate typography, spacing, and layout
